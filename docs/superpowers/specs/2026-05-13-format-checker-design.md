# 论文格式检测器设计

## 目标

构建一个本地 Python 窗口程序，用户选择 Word 文档后，程序按模板中可由 `python-docx` 解析的格式要求检测，并输出不符合要求的原文、当前位置、当前格式和应有格式。

## 范围

第一版只检测 `.docx`。如果用户选择 `.doc`，程序明确提示需要先转换为 `.docx`，不做静默转换或假成功。

可检测项目包括：
- 页面大小、页边距、页眉文字。
- 段落字体、字号、加粗、对齐、首行缩进、固定行距。
- 摘要、ABSTRACT、关键词、Key words。
- 一级至五级标题格式。
- 正文段落格式。
- 图标题、表标题和参考文献格式。

暂不自动判断项目包括：
- 目录页码是否真实准确。
- 图片是否确实位于标题上方。
- 表格是否确实紧跟表标题。
- 一级标题是否物理另起一页。
- 参考文献换行是否与作者首字严格对齐。

## 架构

程序分为四层：
- `document_model.py`：从 `.docx` 提取段落、运行片段、表格、页面设置和页眉。
- `rules.py`：定义可解析规则并生成违规项。
- `report.py`：把违规项格式化为窗口和文本报告。
- `app.py`：Tkinter 窗口，负责选择文件、运行检测、显示和保存报告。

核心检测逻辑不依赖 UI，便于测试。

## 错误处理

不支持的 `.doc` 文件直接返回明确错误。损坏或非 Word 文件抛出可见错误并显示在窗口中。

## 测试

使用 `pytest` 覆盖：
- 规则能识别错误字体、字号、加粗、对齐、行距和缩进。
- `.doc` 文件被明确拒绝。
- 报告包含原文、问题、当前格式和应有格式。
